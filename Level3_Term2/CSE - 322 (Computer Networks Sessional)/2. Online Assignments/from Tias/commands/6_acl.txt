#(config) How to configure an ACL to filter vty traffic. First, a local database entry for a user ADMIN and password class is configured. The vty lines on R1 are configured to use the local database for authentication, permit SSH traffic, and use the ADMIN-HOST ACL to restrict traffic.

username ADMIN secret class
ip access-list standard ADMIN-HOST
remark This ACL secures incoming vty lines
permit 192.168.10.10
deny any
exit
line vty 0 4
login local
transport input telnet
access-class ADMIN-HOST in
end

#(config) The SURFING ACL permits HTTP and HTTPS traffic from inside users to exit the G0/0/1 interface connected to the internet. Web traffic returning from the internet is permitted back into the inside private network by the BROWSING ACL. The SURFING ACL is applied inbound and the BROWSING ACL is applied outbound on the R1 G0/0/0 interface.

ip access-list extended SURFING
Remark Permits inside HTTP and HTTPS traffic
permit tcp 192.168.10.0 0.0.0.255 any eq 80
permit tcp 192.168.10.0 0.0.0.255 any eq 443
exit

ip access-list extended BROWSING
Remark Only permit returning HTTP and HTTPS traffic
permit tcp any 192.168.10.0 0.0.0.255 established
exit
interface g0/0/0
ip access-group SURFING in
ip access-group BROWSING out
end

show access-lists


#(config) The PERMIT-PC1 ACL permits PC1 (192.168.10.10) TCP access to the FTP, SSH, Telnet, DNS , HTTP, and HTTPS traffic. The REPLY-PC1 ACL will permit return traffic to PC1. • The PERMIT-PC1 ACL is applied inbound and the REPLY-PC1 ACL applied outbound on the R1 G0/0/0 interface.

ip access-list extended PERMIT-PC1
Remark Permit PC1 TCP access to internet
permit tcp host 192.168.10.10 any eq 20
permit tcp host 192.168.10.10 any eq 21
permit tcp host 192.168.10.10 any eq 22
permit tcp host 192.168.10.10 any eq 23
permit tcp host 192.168.10.10 any eq 53
permit tcp host 192.168.10.10 any eq 80
permit tcp host 192.168.10.10 any eq 443
deny ip 192.168.10.0 0.0.0.255 any
exit
ip access-list extended REPLY-PC1
Remark Only permit returning traffic to PC1
permit tcp any host 192.168.10.10 established
exit
interface g0/0/0
ip access-group PERMIT-PC1 in
ip access-group REPLY-PC1 out
end
