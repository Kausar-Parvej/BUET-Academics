### Configure the LAN Interface on R1
interface GigabitEthernet0/0
ip address 192.168.1.1 255.255.255.0
no shutdown

### Configure the WAN Interface on R1 (Inter-Router Network)
interface GigabitEthernet0/1
ip address 10.0.0.1 255.255.255.252
no shutdown

### Set Up NAT on R1 (for Internal Network to Reach External Servers)
access-list 1 permit 192.168.1.0 0.0.0.255
ip nat inside source list 1 interface GigabitEthernet0/1 overload

### Set NAT Inside and Outside
interface GigabitEthernet0/0
ip nat inside
exit

interface GigabitEthernet0/1
ip nat outside
exit

### Add a Static Route on R1 to Reach the External Server Network
ip route 192.168.2.0 255.255.255.0 10.0.0.2

### Configure the WAN Interface on R2 (Inter-Router Network)
interface GigabitEthernet0/0
ip address 10.0.0.2 255.255.255.252
no shutdown

### Configure the LAN Interface on R2 (Server Network)
interface GigabitEthernet0/1
ip address 192.168.2.1 255.255.255.0
no shutdown

### Set Up Routing on R2 to Reach the Internal Network
ip route 192.168.1.0 255.255.255.0 10.0.0.1
