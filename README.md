# BUET-Academics

Academic archive of my undergraduate work in CSE, BUET. This repository contains lab works, assignments, projects, and course materials organized by academic level and term.

## Structure

The repository is grouped chronologically:

- Level1_Term1
- Level1_Term2
- Level2_Term1
- Level2_Term2
- Level3_Term1
- Level3_Term2
- Level4_Term1
- Level4_Term2

Each term folder contains course-specific subfolders (for example: C programming, CSE-108, DSA sessionals, operating systems, software engineering, machine learning, and more).

## What Is Included

- Programming assignments and problem solutions
- Course projects and project source code
- Lab reports, notes, and supporting documents
- Practice problems from online/offline sessions

The content spans multiple languages and technologies, including C, C++, Java, Python, and related tooling used across different courses.

## How To Use

1. Open the folder for your target level and term.
2. Go into the relevant course directory.
3. Explore source files, reports, and project folders as needed.

## Notes

- Folder names are kept close to their original academic naming.
- This repository is primarily an academic archive and may include draft files or compiled artifacts from coursework.
